# 矿产资源综合利用 - 绿色矿山建设

基于Vue 3开发的矿产资源综合利用展示页面。

## 功能特性

- 🏭 实景图展示园区布局
- 🔄 完整的工业生产流程图
- 🌱 环保处理流程展示
- ♻️ 循环经济理念展示
- 📱 响应式设计

## 安装和运行

### 安装依赖
```bash
npm install
```

### 开发模式
```bash
npm run dev
```

### 构建生产版本
```bash
npm run build
```

### 预览生产版本
```bash
npm run preview
```

## 技术栈

- Vue 3
- Vite
- CSS3

## 页面结构

### 上方实景图区域
- 展示工业园区/矿区实景
- 7个功能区域标签：
  - 采矿作业
  - 高附加值产品
  - 绿色矿山
  - 生态修复
  - 生态友好型产业
  - 循环经济
  - 智能管控中心

### 下方流程图区域

**第一层**: 矿产资源综合利用 (主题)

**第二层**: 主流程
- 采矿 → 选矿 → 冶炼 → 深加工 → 产品 → 废弃物

**第三层**: 环保处理
- 废渣处理 → 废水处理 → 废气处理 → 余热回收 → 资源化利用

**第四层**: 绿色矿山建设 (目标)

## 自定义

如需替换实景图，请将图片文件命名为 `mining-scene.jpg` 并放置在 `public` 目录下。
