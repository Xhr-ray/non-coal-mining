# 按钮详细描述配置指南

## 📝 如何添加长文本和图片

### 📸 **图片配置方法**

在 `buttonDetails.js` 中，为每个按钮添加 `images` 数组：

```javascript
export const buttonDetails = {
  1: {
    title: '地质勘探',
    // ... 其他配置

    images: [
      {
        src: '/exploration-1.jpg',        // 图片路径（相对于public目录）
        caption: '地质勘探作业现场',     // 图片说明
        alt: '勘探设备和工作人员'        // 图片替代文字
      },
      {
        src: '/exploration-2.jpg',
        caption: '钻探岩心采样',
        alt: '钻探获取的岩心样本'
      }
    ],
  }
}
```

### 📝 **长文本配置方法**

为按钮添加 `longDescription` 字段，支持 Markdown 格式：

```javascript
longDescription: `
# 地质勘探的重要性

地质勘探是矿山开发的首要环节，是所有矿山建设的基础工作。

## 主要工作内容

### 1. 查明矿体特征
- **矿体形态**: 确定矿体的空间分布、形状和大小
- **矿石品位**: 分析矿石中有用组分的含量和分布规律
- **地质构造**: 查明矿区的褶皱、断层、节理等构造特征

### 2. 勘探方法选择
我们采用多种勘探手段相结合的方式：

- **地质调查**: 通过地表地质测绘，了解矿化线索
- **物探方法**: 利用磁法、电法、地震等物理探测方法
- **化探分析**: 通过土壤、岩石地球化学测量发现异常
- **钻探验证**: 通过岩心钻探直接获取矿体信息

### 3. 勘探成果应用
地质勘探的最终成果包括：
- 矿体三维模型和资源储量估算
- 开拓方案和采矿方法选择
- 选矿工艺流程设计
- 经济评价和环境评估

高质量的地质勘探工作为矿山的后续建设和生产提供了可靠的地质依据。
`,
```

### 🖼️ **图片文件放置**

1. 将图片文件放到 `public/` 目录中
2. 在配置中使用 `/图片名.jpg` 的格式引用
3. 支持的图片格式：jpg, jpeg, png, gif, webp

### ⚙️ **配置字段说明**

#### **必需字段**
- `title`: 按钮标题
- `shortDescription`: 简短描述（用于快速浏览）
- `features`: 特点列表
- `stats`: 统计数据

#### **可选字段**
- `longDescription`: 长文本描述（支持Markdown格式）
- `images`: 图片数组

### 📄 **完整配置示例**

```javascript
export const buttonDetails = {
  1: {
    title: '地质勘探',
    shortDescription: '地质勘探是矿山开发的基础工作...',
    longDescription: `
# 地质勘探的重要性

地质勘探是矿山开发的首要环节。

## 主要工作
1. 查明矿体特征
2. 勘探方法选择
3. 勘探成果应用
    `,
    images: [
      {
        src: '/exploration-1.jpg',
        caption: '勘探现场',
        alt: '勘探作业'
      }
    ],
    features: [
      '综合运用多种勘探手段',
      '高精度钻探技术',
      '三维地质建模'
    ],
    stats: {
      '勘探面积': '2.5平方公里',
      '钻孔数量': '156个'
    }
  }
}
```

### 🎨 **Markdown支持**

#### **支持的Markdown语法**
- **标题**: `# H1`, `## H2`, `### H3`, `#### H4`
- **粗体**: `**粗体文字**`
- **斜体**: `*斜体文字*`
- **列表**: `- 无序列表` 或 `1. 有序列表`
- **段落**: 空行分隔段落

#### **显示效果**
- 标题会渲染为彩色标题
- 粗体文字显示为高亮色
- 列表自动格式化
- 段落自动分段

### 📋 **配置建议**

1. **优先使用短文本**:
   - 对于简单按钮，只使用 `shortDescription`
   - 长文本会占用较多空间

2. **图片数量控制**:
   - 建议每个按钮2-4张图片
   - 图片会自动网格布局
   - 图片大小统一为200px高度

3. **Markdown格式化**:
   - 使用标题分隔不同部分
   - 使用列表列举要点
   - 粗体强调重点内容

4. **图片优化**:
   - 图片建议尺寸：800×600px
   - 文件大小控制在500KB以内
   - 使用清晰的图片说明

### 🔧 **快速开始**

1. **准备图片**: 将图片放入 `public/` 目录
2. **配置描述**: 在 `buttonDetails.js` 中添加长文本和图片配置
3. **测试效果**: 点击按钮查看显示效果
4. **调整优化**: 根据显示效果调整内容

现在您可以为每个按钮添加丰富的详细描述和图片了！
